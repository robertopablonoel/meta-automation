## What This Project Does

Processes raw UGC TikTok videos into organized Meta ad copy, grouped by creative concept,
with a dashboard for reviewing copy and exporting a ready-to-import Meta bulk upload file.

## Running the Pipeline

Always use the venv Python:

  # Activate venv (optional, allows typing just "python")
  source venv/bin/activate

  # Full pipeline — English videos only
  venv/bin/python -m pipeline.run --language en

  # Full pipeline — Spanish videos only
  venv/bin/python -m pipeline.run --language es

  # Re-run from scratch (ignore all checkpoints)
  venv/bin/python -m pipeline.run --language en --force

  # Step-by-step flags (for debugging)
  --preprocess-only    # Pass 0: extract frames + transcripts via Whisper
  --describe-only      # Pass 1: Claude describes each video
  --subgroup-only      # Pass 2: CLIP visual sub-grouping
  --discover-only      # Pass 3: category discovery
  --classify-only      # Pass 3c: classify videos into categories
  --generate-copy      # Pass 4: generate ad copy variations

Language filtering happens after Pass 0 using Whisper's detected_language field.
Pipeline checkpoints after each pass — re-running without --force resumes from last checkpoint.

---

## Pipeline Passes

Pass 0: Whisper transcribes all videos, detects language (es/en)
Pass 1: Claude describes each video (visual elements, tone, awareness level)
Pass 2: CLIP visual sub-grouping (images only — usually skipped for video-only batches)
Pass 3: Claude discovers creative concept categories from video descriptions
Pass 3c: Claude classifies each video into a category
Pass 4: Claude generates 5 ad copy variations per category
Consolidation: Merges all outputs into consolidated_{lang}.json, adds ad_filename field
Rename: Copies input videos to output/renamed_videos/ with ad_filename as the filename

---

## ad_filename Format

Each video in consolidated_{lang}.json has an ad_filename field computed during consolidation:
  {Category_Label}-{Hook_from_transcript}.{ext}

  e.g. Relationship_Betrayal_Bombshell-I_found_out_that_my_twoyearold.mp4

Rules:
- Category label: concept name title-cased, spaces replaced with underscores
- Hook: first 6 words of transcript, punctuation stripped, joined with underscores
- Separator: single hyphen (no spaces anywhere)
- Collisions: _2, _3 appended (two videos with same hook get unique names)
- These renamed copies go in output/renamed_videos/ — upload THESE to Meta, not originals

  (or ?lang=es for Spanish)

- Copy buttons for Primary Text, Headline, Description (individually or all at once)
- Video pills show the hook slug from ad_filename (not raw original filename)
- ↓ Export for Meta button — generates meta_bulk_upload_{lang}.xlsx

## Meta Bulk Upload Export

The export button:
1. Loads meta_export_template.xlsx as base (clones row 2 for all new ads)
2. Writes one row per video (not per category — each video = one ad)
3. Overwrites: Campaign ID, Campaign Name, Ad Status, Ad Set Name, Ad Name,
   Body, Title, Link Description, Video File Name, Link

Current hardcoded values:
  Campaign:    Spicy Cubes Dailies - English UGC
  Campaign ID: 120241040507080467
  Ad Set:      Batch #3
  Link:        https://www.spicycubes.com/products/spicy-cubes-pineapple-dailies-for-her-2

To change campaign/ad set: edit the CAMPAIGN, CAMPAIGN_ID, AD_SET constants
in the exportToMeta() function in dashboard/meta-ads-dashboard.html.

The export uses Video File Name (not Video ID). This requires uploading the renamed
videos from output/renamed_videos/ directly during the Meta bulk import (drag into the
Videos tab of the import dialog). Meta matches by exact filename.

10MB limit per video on bulk import — compress with ffmpeg if needed:
  ffmpeg -y -i input.mp4 -c:v libx264 -b:v 300k -c:a aac -b:a 128k output.mp4
  (adjust -b:v based on video duration to stay under 10MB)

## Known Issues & Solutions

1. Truncated JSON from Claude on long videos
   Fixed: max_tokens bumped to 2048 in pipeline/copy_generator.py for both
   image and video describe calls. If issue recurs on very long videos, bump further.

2. Video File Name mismatch on bulk import
   Root cause: Meta's Video File Name lookup only works if the file is uploaded
   during the import itself (not pre-uploaded to media library).
   Solution: use output/renamed_videos/ files and upload them in the Videos tab
   of the import dialog.

3. Duplicate ad_filename collisions
   Fixed: run_rename_videos appends _2, _3 etc. and updates consolidated JSON.

4. Dashboard showing stale data
   Fixed: fetch URL includes ?t=Date.now() cache-buster. Hard refresh (Cmd+Shift+R)
   or incognito as fallback.

5. Campaign creating new instead of matching existing
   Fixed: Campaign ID is explicitly written in the export (not just Campaign Name).
   Meta matches by ID, not name.

6. "Batch #1 and Batch #3 both created"
   Root cause: Ad Set ID from template row was pointing to old ad set.
   Fixed: Ad Set ID is in CLEAR_FIELDS — cleared so Meta looks up by Ad Set Name.

## Ad Copy Structure

Each category gets 5 variations. Each variation has:
  primary_text   (long form, 150-300 chars typically)
  headline       (short, punchy)
  description    (1 line, benefit/CTA focused)

All copy is Spanish for --language es runs, English for --language en runs.
Brand: Spicy Cubes — female libido/wellness gummies, clinical-dose enzymes (not probiotics).
Key differentiators: 6g gummy (vs 2g competitors), 600mg fenugreek, 500mg tribulus, 30mg saffron.

## Things To Know About Cole's Workflow

- Runs English and Spanish as separate pipeline runs, separate batches in Meta
- Does NOT use meta_uploader.py for automated video upload (ban risk concern)
- Videos sourced from TikTok creator accounts (cubesnat, getaspicycube, etc.)
- Uses Meta bulk upload for ad creation — manual video upload, then import xlsx
- Partnership ads (creator as primary identity) are a future goal but require
  creator approval flow — not yet implemented
- Dashboard server must be running before opening the dashboard URL
- Always run pipeline from project root with venv active or venv/bin/python prefix
